# KDCCE Remastered

Group Project — Module 6.

## Structure

```
kdcee-remastered/
├── frontend/     Frontend application code
├── backend/      Backend application code
└── .env.example  Environment variable template
```

## Getting started

Copy `.env.example` to `.env` and fill in your local values before running either side.

## Branches

`main` is the integration branch. Each team member works on their own
`<name>-frontend` / `<name>-backend` branch and opens a pull request into
`main` when ready — nothing is merged automatically.
